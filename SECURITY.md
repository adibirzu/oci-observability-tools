# Security policy

## Reporting

Do not open a public issue for a suspected credential, customer identifier, or private endpoint. Contact the repository owner through GitHub's private vulnerability reporting feature.

Never include credentials or tenant data in a report. Replace identifiers with angle-bracket placeholders and use documentation IP address ranges.

## Scope

The helpers are offline and do not access an OCI tenancy. Security reports about redaction bypasses, unsafe query handling, installer path handling, and dependency risks are welcome.
