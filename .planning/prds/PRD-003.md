## Purpose

Help assistants write OCL that follows documented Log Analytics conventions, and make agent-driven query calls safe to forward to an MCP query tool.

## Users

Assistants and engineers writing Log Analytics queries, and agent tooling that forwards queries to an MCP query tool.

## Scope

- OCL001-OCL009 rule table and severities
- lint JSON output shape
- sanitize_for_mcp rejections
- cookbook and skill example hygiene

## Non-goals

- live execution against Log Analytics
- Sigma conversion (PRD-004)
